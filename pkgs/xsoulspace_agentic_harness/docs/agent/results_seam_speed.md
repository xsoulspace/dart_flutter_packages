## Reference (pre-0027)

Published R7 row: a read decision (zero moves) cost **~68,775 ms** — the
`dart test` cold compile in the unconditional final gate
([results_r7.md](results_r7.md)). The tier planner skipped only the
in-loop grade; the final gate always ran.

## Measured — the read path (the fix)

| path | backend | wall | gate |
| --- | --- | --- | --- |
| directive read (`[scan] [zoom …]`), scripted (LLM-free) | scripted handler | **34 ms** | no task (mechanical) |
| directive read (`[scan] [zoom …]`), real AFM | `apple_foundation_afm` | **54 ms** | no task (mechanical) |

≈ **1,300–2,000× faster than the published row.** The read is a zoom cut
over the map-graph (ADR 0023/0024) — mechanically correct to be
sub-second; routing it through a build oracle was the category error.

## Measured — the other prompt classes (real AFM)

| prompt class | wall | gate |

The `[read-only]` and mutation rows are the SAME order of magnitude —
the difference is that read rows are now bounded by model latency alone,
while mutation rows keep the complete honest oracle. Fail-fast
`analyzer_before_tests` triggers only when the gate is a test command and
the jail has a resolved package config (bare-file fixtures skip it
honestly).

## pi-side (structural, measured by the driver gates on next run)

- connect-if-live socket attach was already first-choice; AOT-first spawn
  (`HARNESSD_AOT`) removes the ~10–15s `dart run` cold start when the
  bundle exists.
- retry budget/backoff are configuration: `PI_HARNESSD_RETRIES`,
  `PI_HARNESSD_BACKOFF_MS`.
- reasoning hints (`reasoning: none|low|high`) ride every `propose_move`;
  `thinking` returns with the move and is captured (chars in the verdict
  line, reused on escalation, never re-projected).
- consent-gate phases remain sequential BY DESIGN (shared consent
  ordering); independent-fixture gates may run concurrently (per-workspace
  single-instance daemons).
