## The loop in one sentence

The world is an ECS graph of beats; a decision opens, agency grants the actor
a model call, the projection system ray-traces a tiny cut of the graph as the
prompt, the handler calls a swappable model, responses come back through
events, tools execute inside the world, and the result is written back as
beats — then the loop sleeps until new work arrives.

## Invariants worth defending

- The handler **never executes tools**; `toolExecutionSystem` does, so native
  (Apple FM) and tag-parsed tool calls share one path.
- Memory is **projection over beat-threads**, never a log; summaries are
  deliberate transforms that stay traceable.
- Projection is **token-budgeted** and fails benchmarks when exceeded. The
  meaning view is a **zoom projection** (`point/local/region/summary`, ADR
  0018); move acks zoom to `point` — O(1) feedback.
- **The cut is a composed document** (ADR 0020): typed slots (goal/map/
  observations/lastVerdict) with per-slot policies; the codec renders slots
  verbatim and NEVER re-ranks; unfilled required slots are named
  `CutViolation`s — the input gate stops dispatch before the model is
  called. Dedup + drop-empty are admission policies, not post-filters.
- **Verification runs as a registered task**: the run-graded verifier's
  subprocess is in-flight work — `canSleep()` must wait for a pending
  verdict to land.
- **model ≠ actor** (ADR 0020 §5): a role = composition + tool surface +
  model binding; many actors may share one model; one local model may
  field a whole squad.
- **Single-writer per file in multi-actor squads**: real fs is shared
  mutable state outside the graph; `FileLockTable` rejects cross-owner
  writes BEFORE the write gate runs.
- One **flush** is the coherence point per phase; `runUntilIdle` must end with
  no pending decisions, agency, awaits, tasks, or stranded events
  (`expectIdle` in test support).
- **Every loop is monotonic-budgeted** (J1.5): `maxToolRounds` per decision
  chain, `maxRetries` for backend errors (survives tool-call continuations),
  `maxGoalAttempts` for failed goal verifications (then `EscalationRequest`
  + thread suspension). `openFreshDecision` is the only budget-reset path
  for host-injected decisions.
- A wired `FlightRecorder` is auto-sampled and dumped on maxTicks
  StateError/SIGINT — a stuck run ships its own post-mortem.
- **New Component classes are appended at the very END** of
  `AgentPlugin.install` — ecsly assigns component ids in registration order;
  mid-chain inserts corrupt host registrations.
- Adding a provider = register an `InferenceClient` builder in
  [ModelRouter]; nothing else changes.
